## 中文
本组织维护基于 FastRPC 的 Qualcomm Hexagon NPU 后端实现，作为 llama.cpp/ggml 的备选方案，对比传统 dspqueue 实现。

### 主要特性
- 兼容上游[高通官方ggml-hexagon实现](https://github.com/ggml-org/llama.cpp/tree/master/ggml/src/ggml-hexagon)
- 源自上游[PR #27642](https://github.com/ggml-org/llama.cpp/pull/27642)

### 仓库列表
- [ggml‑hexagon](https://github.com/ggml‑hexagon/ggml‑hexagon): 主后端仓库

## English
This organization maintains FastRPC‑based Qualcomm Hexagon NPU backend for ggml / llama.cpp, as an alternative to Qualcomm's dspqueue implementation.

### Key Features
- Compatible with [Qualcomm's dspqueue-based ggml-hexagon](https://github.com/ggml-org/llama.cpp/tree/master/ggml/src/ggml-hexagon)
- Originated from upstream [PR #27642](https://github.com/ggml-org/llama.cpp/pull/27642)

### Repositories
- [ggml‑hexagon](https://github.com/ggml‑hexagon/ggml‑hexagon): Main backend repository
